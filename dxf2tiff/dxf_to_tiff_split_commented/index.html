DXF → TIFF / PNG 変換サンプル（分割版）

DXFを読み込み、原点 (0,0) からA判用紙サイズ分を切り出して画像化します。

入力・出力設定

DXFファイルをドラッグ＆ドロップ またはクリックしてファイルを選択
DXFファイルを読み込んでください。
切り出し範囲
X = 0 ～ 用紙幅、Y = 0 ～ 用紙高さ（mm）。用紙外の図形は出力しません。図枠の内側余白はそのまま残ります。
サンプル版の制限
dxf-parserで解析できる図形を描画します。DIMENSION・INSERT・HATCH・特殊線種などは、DXFの構成によって表示が不完全な場合があります。寸法値や印刷スタイルの完全再現を保証するものではありません。
